LabMan documentation
====================

LabMan is a Django-based laboratory management system for shared research facilities.  It manages accounts,
research groups, equipment, locations, access roles, safety-document sign-off, bookings, charging rates, and cost
centres.

Start with :doc:`project_overview` for the purpose of the system, its domain boundaries, the responsibilities of each
Django application, and the main request and integration flows.
